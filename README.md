# Analyse-comparative-des-modèles-de-séries-temporelles-dans-la-gestion-de-la-liquidité-bancaire
Ce projet porte sur l’analyse comparative des modèles de séries temporelles appliqués à la gestion de la liquidité bancaire. L’objectif est d’évaluer la performance de différents modèles statistiques et économétriques (ARMA, ARIMA, etc.)
